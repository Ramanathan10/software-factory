# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and anywhere else the project is represented.

## Reporting

Report unacceptable behavior to the maintainers privately, either with GitHub's **Report content** option on the comment or issue, or by contacting a maintainer through their GitHub profile. Reports are kept confidential.

Maintainers may edit or remove comments, commits, issues and other contributions that break this code of conduct, and may block a contributor who keeps doing so.
